MISE EN LIGNE SUR GITHUB PAGES

1. Ouvre le dépôt GitHub IMMEDIA.
2. Supprime les anciens fichiers du dépôt si nécessaire.
3. Décompresse cette archive sur ton ordinateur.
4. Envoie DIRECTEMENT le contenu du dossier dans la racine du dépôt :
   - index.html
   - audience.html
   - offres.html
   - realisations.html
   - contact.html
   - dossier assets
   - fichier .nojekyll

IMPORTANT : ne dépose pas le dossier IMMEDIA-GITHUB-PAGES lui-même dans le dépôt.
Le fichier index.html doit être visible immédiatement à la racine du dépôt.

5. Dans GitHub : Settings > Pages.
6. Source : Deploy from a branch.
7. Branch : main, dossier /(root), puis Save.
8. Attends 1 à 3 minutes et recharge la page avec Ctrl+F5 ou Cmd+Shift+R.
